# Build verification results

Fixed regression counts: 46, 215, 520, 5773. The first reproduces the reference
SHA prefix 4c37caf1201fe83d. Both engines and both checkers agree; complete
hashes, statistics and execution records are in immutable JSON certificates.
N0 gives 507.62974052227594 for C(10000,20000,1000), whose exact count is 520.
The test suite covers randomized claims, Pocklington mutations, exact oracles,
canonical encodings, Montgomery boundary arithmetic and protocol tampering.

The problem asks for exact Mersenne factor censuses and predictive laws that
survive data withheld before computation. This build establishes reproducible
finite regression censuses (C0 reproduction and C2 explicit finite values).
Independent exact checkers and two exhaustive algorithms provide the evidence.
This could support reliable future experiments and assignment allocation. It
does not establish a new law, operator-confirmed sealed result or credited new
factor. The single next experiment is the preregistered L002 open demonstration.
