\begin{abstract}
Two independent exhaustive programs found 487,025 prime-factor pairs
for prime exponents $10{,}000{,}001\le p\le30{,}000{,}000$ and multipliers
$k\le10{,}000$ in $q=2kp+1$. Independent checkers accepted every pair.
An external operator, in a message relayed to the project, confirmed the
original region 2 census hash and all four reported summary cells against
withheld values. Replacing the project's Poisson multiplicity approximation
by a zero-fit Poisson-binomial model improves the fixed composite score by
35.487 on region 2 and 69.789 on the full design. Smaller residuals remain.
This is a reproducible empirical confirmation of established heuristics, not
a new law. Prediction-first ordering has local Git evidence, but the
independent operator did not receive the prediction fingerprint before the run.
\end{abstract}

\section{Finite problem and exact computation}
For prime $p$, let $M_p=2^p-1$ and define
\[
 I_{p,k}=\mathbf{1}\{q=2kp+1\text{ is prime and }q\mid M_p\},
 \qquad J_p=\sum_{k=1}^{10{,}000}I_{p,k}.
\]
The census records each pair $(p,k)$ once. Its summaries are the number of
pairs $C=\sum_pJ_p$, the numbers of exponents $A_j=\#\{p:J_p\ge j\}$
for $j=1,2$, and the maximum $M=\max_pJ_p$. All exponent endpoints are inclusive.
Region 2 is $[10{,}000{,}001,20{,}000{,}000]$; the extension is
$[20{,}000{,}001,30{,}000{,}000]$. The full design is their union.

\midrule

The two C programs enumerate in different loop orders and use different
modular-arithmetic and sieving implementations. All 40 contiguous chunks
agreed byte for byte. A fresh Python checker and an independent C checker
verified each chunk's prime exponents, prime factors and divisibility.
The final audit checked complete coverage, canonical sorted pairs, hashes,
certificates, source provenance and an independent recount of the summary
cells. These are bounded small-$k$ factor censuses, not counts of Mersenne
primes or newly credited factor discoveries. Region 1 was not rerun.

\section{Relationship to established work}
Shanks and Kravitz studied Mersenne divisor counts indexed by $k$~\cite{sk}.
Wagstaff gives the corresponding pair-weight heuristic, discusses limits of
Poisson modeling, and already writes a product of no-factor probabilities
on page 387, equation (4)~\cite{wagstaff}. Thus the correction below is to
the project's \emph{L001 Poisson implementation}, not a refutation of
Wagstaff's full treatment. Independent Bernoulli sums form the standard
Poisson-binomial distribution~\cite{hong}.

\section{Frozen models and prospective design}
For admissible $k\equiv0$ or $-p\pmod4$, the shared L001/L003 pair mean is
\begin{equation}
 w_{p,k}=\frac{2C_2}{k\log(2kp)}
 \prod_{\substack{r\mid k\\r>2\text{ prime}}}\frac{r-1}{r-2},
 \qquad C_2=0.6601618158468696.
\end{equation}
Other $k$ have weight zero. These are heuristic means, not exact
probabilities proved for Mersenne factors. Put $\mu_p=\sum_kw_{p,k}$.
L001 uses $J_p\sim\mathrm{Poisson}(\mu_p)$, so
$\E A_1=\sum_p(1-e^{-\mu_p})$ and
$\E A_2=\sum_p[1-e^{-\mu_p}(1+\mu_p)]$.

L003 instead models each candidate as one independent Bernoulli indicator,
with generating function
\begin{equation}
 G_p(z)=\prod_{k=1}^{10{,}000}(1-w_{p,k}+w_{p,k}z),\qquad
 P_{p,0}=G_p(0),\quad
 P_{p,1}=P_{p,0}\sum_k\frac{w_{p,k}}{1-w_{p,k}}.
\end{equation}
It predicts $\E A_1=\sum_p(1-P_{p,0})$ and
$\E A_2=\sum_p(1-P_{p,0}-P_{p,1})$ without fitted parameters.
Its mean $\mu_p$ is unchanged; its variance is
$\mu_p-\sum_kw_{p,k}^2$, explaining a finite-trial reduction from the
Poisson variance. Assuming independence across exponents, with $F_p$ the
per-exponent cumulative distribution,
\begin{equation}
 \E M=\sum_{j\ge0}\left(1-\prod_p F_p(j)\right).
\end{equation}
Coefficient recursion through degree 24, tail bounds, direct small examples
and 24/32-node interpolation comparisons checked numerical accuracy before
commitment. Independence within and across exponents remains an assumption.

The other frozen comparators are N0, a small-prime-sieved pair heuristic,
and L002, N0 multiplied by fixed local correction factors for primes
$53\le r\le997$. Both use Poisson multiplicities; neither fits the observed
counts. Exact definitions and source hashes accompany the prediction file.

The registered score is the composite deviance
\begin{equation}
 D(y,\nu)=\sum_c 2\left(\nu_c-y_c+y_c\log\frac{y_c}{\nu_c}\right),
\end{equation}
with the usual zero-count limit. The cells are total factors, 14 dyadic
$k$ buckets, all residues modulo $3,4,5,8,12$, $A_1$, $A_2$, and $M$ once.
They overlap, so this is not an independent likelihood ratio or a calibrated
significance test. A lower score by at least 14 is the fixed comparison rule.

Before commitment, each pair of laws was checked in both truth directions.
If means are $a_c$ and $b_c$, the expected gain of $a$ over $b$ when $a$ is
true is $2\sum_c[b_c-a_c+a_c\log(a_c/b_c)]$. This identity requires the
stated means, not independent cells. The threshold is an expected-separation
criterion, not an 80\% power calculation.

N0/L002 gave only 10.473/10.464 on region 2, below 14, prompting the
pre-run extension. On the full design N0/L002 gives 20.342/20.324 and
L001/L003 gives 34.593/34.478; all six primary pairs pass in both directions.
The original region 2 is retained as a separate sealed scope. The extension
has no operator seal, and the union is not an independent replication.

The combined residual is the sum of the two regional residuals, not a third
independent observation. These targets count \emph{at least} one and two
factors. The exactly-one count is their difference; an exactly-two
discrepancy is not determined from these two cells alone.

Relative to observed full-design counts, L003's signed prediction errors
are $+0.0846\%$ for total factors, $-0.2200\%$ for $A_1$ and $+0.9956\%$
for $A_2$. Thus accuracy of 0.1--0.3\% is not a uniform description of all
cells. The finite Bernoulli model explains much of the original discrepancy,
but does not remove it. Reviewer-supplied sigma estimates are not treated
as calibrated tests: their covariance calculation was not supplied, and the
registered composite statistic supplies no such calibration. These results
establish neither a new arithmetic repulsion law nor that every residual
is ordinary noise. No model was refitted after these outcomes were seen.

\textbf{Audit the saved experiment.} Use a full, non-shallow Git checkout
with all tracked data and the history containing the prediction and results
commits listed in section 5. A source-only ZIP cannot establish the Git
provenance checked by the audit. From the repository root, with Python
3.10+ and Git available, run:
\begin{verbatim}
python -m ops.vault_report
\end{verbatim}
This checks saved bytes, source provenance, coverage, certificates and
summary counts, recomputes the frozen scores, and refreshes the audit
outputs. It does not enumerate factors or supply an external timestamp.

\textbf{Recompute the censuses.} For an independent computational replay,
use Python 3.12 (the original run used 3.12.14), Git and GCC or Clang with
C11 and unsigned 128-bit support; Windows uses MinGW-w64. From a separate
checkout, install the pinned research dependency and run:
\begin{verbatim}
python -m pip install -r requirements-research.txt
python -m ops.build
python -m unittest discover -s tests -v
python -m ops.verify
\end{verbatim}
The final command rechecks every stored certificate with both checkers and
re-enumerates every stored census with both engines, including overlapping
regional and union certificates. It is substantially more work than the
saved-artifact audit. Compare canonical census hashes with section 5;
recomputed outcomes are verification, not new sealed tests. No census was
rerun for this report revision. Further command details are in \texttt{README.md}.

\textbf{Conclusion.} This bounded P12 comparison is closed as an empirical
confirmation with a documented residual and a documented provenance
limitation. It makes no new-theorem, new-law or credited-factor claim.
The observed bands must not be reused as fresh tests of a revised model.
